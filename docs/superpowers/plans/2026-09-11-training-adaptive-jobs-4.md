# Training, Adaptive Regions, Recognition & Jobs (plan 4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Templates learn from many samples (spec §11), fields re-read themselves in a widened radius around the last good position when the drawn region misses (§17.2), incoming files are recognised by layout similarity when the issuer ΑΦΜ gives no template (§14.7), and many files can be scanned with a template as a background job with live progress and Excel export (§12, §13).

**Architecture:** Four thin layers on the existing template runner. Pure modules hold the logic (`adaptive.ts`, `training.ts`, `fingerprint.ts`, `jobs-logic.ts`) and are unit-tested; server modules (`samples.ts`, `recognize.ts`, `jobs.ts`) wrap Prisma/Bunny/vision. The adaptive read plugs into `extractTemplateFields` after the existing one-shot retry; `lastGood` is updated only from confirmed values. Recognition is a fallback inside `runMatchingTemplate`. Jobs run in-process: a claim loop started from `instrumentation.ts`, one job at a time per instance, cancel-aware, with stale-item recovery. The tables `TemplateSample`, `TemplateJob`, `TemplateJobItem` already exist (migration `20260910090000_extraction_templates`) and have no reader/writer yet.

**Tech Stack:** Next.js 16 App Router (`instrumentation.ts` `register()`), Prisma 7 (hand-written SQL migrations, `npx prisma migrate deploy` + `npx prisma generate` only — never `migrate dev`/`reset`/`db push`), zod 4, vitest 4 (`lib/**/*.test.ts`, prisma mocked via `vi.hoisted` + `vi.mock('@/lib/db')`, `server-only` shimmed), Bunny private storage (`lib/bunny`), pdfjs text layer (`lib/templates/pdf-text.ts`), vision via `lib/templates/vision.ts`, exceljs, DG design system (Greek UI, Sisyphus blue, warm neutrals, `react-icons/fi`, sonner).

**Ground rules:** worktree `.claude/worktrees/plan4` (branch `feat/training-jobs`); never `git stash`; stage by path; commits end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`; no SoftOne writes; no paid LLM/vision calls from tests or scripts (mock `callVision`/`readCropValue`); `.env` values come from the user.

- [ ] `adaptive.ts` tests then code: `widenBbox([x,y,w,h], 0.15)` grows by 15 % of w/h on each side, clamped to 0..1 (`clampBbox`); `searchBoxes(field: {region, lastGood})` → `[field.region.bbox]` then, when `lastGood` exists and differs, `widenBbox(lastGood.bbox)`, else `widenBbox(field.region.bbox)`; `updateLastGood(prev, page, bbox, at)` → moving average `n` capped at 10 (`bbox_i = (prev_i*n + new_i)/(n+1)`), page = latest; `updateLastGood(null, …)` → `{page, bbox, at, n:1}`.
- [ ] `training.ts` tests then code: `normalizeForCompare(v, valueType)` (TEXT: `normalizeLineText`-style lowercase/accents/spaces; NUMBER/CURRENCY: `parseNumber` round 2; DATE: ISO; LIST/TABLE: JSON of normalized cells); `scoreSamples(fields, samples: {status, expected, lastResult}[])` counts only VERIFIED samples; per field `ok/total/score` where total = verified samples having `expected[key]` defined; overall = mean of required fields' scores (all fields when none required); `verified` count; `trainingGate({minTrainingScore, minTrainingSamples, trainingScore, verifiedSamples})` → `{ok:true}` when `minTrainingSamples === 0` or (`verifiedSamples >= minTrainingSamples && trainingScore >= minTrainingScore`), else `{ok:false, reason: 'need_samples'|'low_score'}`.
- [ ] `fingerprint.ts` tests then code: `Fingerprint = {afm: string|null, issuer: string|null, words: string[], aspect: number|null}`; `buildFingerprint({issuerName, afm, text, aspect})` — tokens via `normalizeGreek`-like fold (reuse `lib/ocr/doc-type-classify.ts` `normalizeGreek` if exported, else `normalizeLineText`), keep tokens of length ≥ 4 that are not pure digits/dates/amounts, drop a small stop-list (ΤΙΜΟΛΟΓΙΟ, ΠΟΣΟΤΗΤΑ, ΣΥΝΟΛΟ, ΦΠΑ, ΑΦΜ, ΗΜΕΡΟΜΗΝΙΑ, ΑΞΙΑ, ΠΕΡΙΓΡΑΦΗ…), take the 40 most frequent; `similarity(a,b)` = `0.4·dice(issuer)` + `0.5·jaccard(words)` + `0.1·(1 − min(1,|Δaspect|/0.3))` (missing parts redistribute weight); `rankTemplates(fp, candidates: {templateId, fingerprints: Fingerprint[]}[])` → best score per template (max over its fingerprints), sorted desc; constants `MATCH_THRESHOLD = 0.55`, `AMBIGUITY_GAP = 0.1`.
